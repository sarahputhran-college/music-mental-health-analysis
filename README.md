# Music & Mental Health – MXMH Survey Analysis

This project analyzes the MXMH (Music & Mental Health) dataset to explore how music preferences relate to mental health indicators such as anxiety, depression, OCD, and insomnia.

The workflow includes:
- Data cleaning & exploration in **Python (Google Colab)**
- Insights from exploratory data analysis
- Dashboard visualizations using **Tableau** and **Power BI**

---

## 📁 Repository Contents

| File | Description |
|------|-------------|
| `mxmh_survey_results.csv` | Original / cleaned survey dataset |
| `Music_and_Mental_Health_Results_Dataset_Analysis.ipynb` | Python notebook for preprocessing & EDA |
| `Music and Mental Health.twb` | Tableau workbook |
| `PowerBI Viz.pbix` | Power BI visualization |

---

## 🧠 Key Steps

### ✅ Data Cleaning
- Handled missing values
- Renamed / standardized category labels
- Removed irrelevant & malformed entries
- Encoded features as needed

### ✅ Exploratory Analysis
- Genre preference distributions
- Correlation between music intensity & mental health indicators
- Patterns across demographics

### ✅ Dashboards
- Built dynamic dashboards in Power BI & Tableau to illustrate relationships and trends.

## 📈 Insights (Sample)
- Certain genres show weak correlations with mental health metrics
- Higher music intensity may have mixed effects on anxiety and depression
- Personal preference and listening context are important mediators

> Full insights and visualizations can be explored via notebooks and dashboards.
